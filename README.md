# Zonda - Playwright Test Automation

This project contains automated tests for the Livabl website using Playwright and the Page Object Model (POM) pattern.

## How to Run

### Installation

```bash
npm install
```

### Run Tests

```bash
npx playwright test
```

### Run tests in Firefox only

```bash
npx playwright test --project=firefox
```

### View Test Report

```bash
npx playwright show-report
```
